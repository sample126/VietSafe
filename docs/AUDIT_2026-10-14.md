# Kiểm tra VietSafe sau chuyển cấu trúc — 14/10/2026

## Các vấn đề tìm thấy và cách xử lý

1. **Đã sửa — Docker NASA:** Dockerfile trước đây không cài `h5py` / NumPy nên token hợp lệ cũng không đủ để xử lý HDF5. Có tùy chọn `ENABLE_NASA=1` ở bước build; chỉ bật khi cần NASA IMERG.
2. **Đã sửa — Render NASA:** `render.yaml` cài `requirements-optional.txt` trong build. Render phải có Internet và tài nguyên đủ cho h5py/NumPy.
3. **Đã sửa — NASA lỗi muộn:** Khi thiếu HDF5 parser, chương trình giờ báo lỗi trước khi tải granule lớn. `/api/live-status` cho biết có cài parser chưa; đây **không phải** kiểm tra quyền truy cập NASA.
4. **Đã bổ sung — Admin:** Bản SQLite gốc không có user admin, `.env.local` thiếu admin password. Chạy `python3 scripts/create_admin.py` để tạo admin bằng prompt ẩn; mật khẩu không lưu vào file cấu hình.
5. **Đã sửa — Mật khẩu:** Không tạo tài khoản mới bằng SHA-256 thuần; PBKDF2-HMAC-SHA256 với salt riêng, vẫn hỗ trợ xác thực và nâng cấp hash cũ sau lần đăng nhập tiếp theo.
6. **Đã bổ sung — Kiểm thử không phụ thuộc npm:** Static tests Node.js có thể chạy bằng `npm test` mà không cài `jsdom`. Test DOM dùng jsdom sẽ được đánh dấu skipped khi chưa cài.
7. **Đã giữ — TomTom/NASA:** `.env` và `.env.local` từ bản gốc được giữ trong bản đóng gói theo yêu cầu chủ sở hữu. Không hiển thị token trong báo cáo.

## Các giới hạn còn lại

- Chưa xác nhận kết nối thực tới TomTom, NASA GES DISC hay Open-Meteo từ môi trường kiểm tra; bài unit test mock/fixture không chứng minh upstream cấp quyền. Token NASA có hạn sử dụng và quyền GPM độc lập.
- Dự án nguồn đang vận hành ở chế độ **live-only**. `/api/snapshot` trả 409, `/api/routes` trả 501; không có mô hình T-GCN thực, không tự suy ra độ sâu ngập của từng đường từ mưa vệ tinh.
- Bản đồ Leaflet được đóng gói offline, nhưng **ảnh nền tile OSM và API upstream yêu cầu Internet**.
- Chưa có nguồn cảm biến IoT / camera thật, bộ thu thập dữ liệu ngập cho từng tuyến đường, pipeline đào tạo/đánh giá ML hay ETL liên tục. API nhập quan trắc chỉ dành cho admin và cần dữ liệu nguồn xác thực.
- SQLite trên hosting có ổ đĩa tạm (như Render Free) có thể bị xóa lúc redeploy / restart. Cần volume bền vững hoặc PostgreSQL và kế hoạch backup trước khi đưa lên production.
- HTTP Python stdlib và giới hạn tốc độ trong bộ nhớ phù hợp prototype, chưa có reverse proxy bảo mật production, giám sát vận hành / logs có cấu trúc / backup.
- Các module `frontend/js/views/enhancements.js`, `tgcn.js` là module demo không tự động tải; không được hiểu là mô hình AI thật.
- Việc theo dõi `.env`/`.env.local` bằng Git **có nguy cơ lộ API key và token** khi push repo công khai; nên để repository Private và không commit mật khẩu admin. Nếu đã công khai token, cần thu hồi và cấp lại.
- Chưa xác minh toàn bộ tương tác người dùng trong browser vì Chromium môi trường kiểm tra chặn truy cập localhost; kiểm tra HTTP và nội dung tĩnh riêng không thay thế e2e.

## Các lệnh kiểm tra

```bash
python3 -m unittest discover -s backend/tests -v
npm test
python3 scripts/kiem_tra_tomtom.py
python3 scripts/kiem_tra_nasa.py
python3 scripts/create_admin.py
python3 backend/run.py --port 8765
```

Chạy kiểm thử upstream trực tiếp khi có Internet:

```bash
python3 scripts/kiem_tra_tomtom.py --live
python3 scripts/kiem_tra_nasa.py --online
```

Nếu dùng NASA trên macOS: `python3 -m venv .venv; source .venv/bin/activate; python3 -m pip install -r requirements-optional.txt`.

Docker NASA:

```bash
docker build --build-arg ENABLE_NASA=1 -t vietsafe-nasa .
docker run --rm -p 8765:8765 --env-file .env vietsafe-nasa
```
